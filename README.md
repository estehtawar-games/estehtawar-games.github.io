# estehtawar-games.github.io

Website studio **EsTehTawar** (GitHub Pages, gratis). Situs statis tanpa build: ubah HTML/CSS, commit, push; tayang dalam 1–2 menit.

- `/`: beranda studio (diorama interaktif: tap maling helm)
- `/parkir-bos/`: halaman game Parkir Bos! Kerajaan Parkir
- `/parkir-bos/privasi/`: kebijakan privasi (sumber naskah: `docs/KEBIJAKAN_PRIVASI.md` di repo ParkirBos)
- `/app-ads.txt`: wajib untuk AdMob (ID penerbit `pub-7685585309524019`)
- `img/sprites`, `img/bg`: gambar dari game (ArtGenerator dan latar SVG), `img/shots`: tangkapan layar HP, `img/og.jpg`: pratinjau tautan

Gaya visual mengikuti game: garis tepi gelap tebal, warna rata, tombol timbul. Font Fredoka + Nunito (Google Fonts).
